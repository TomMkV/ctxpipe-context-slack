# CTX-166: GitHub repository rename leaves the mirror on the old path

Renaming a repository on GitHub updates the display name but leaves the mirror path on the old slug. Links in the graph 404.

## Acceptance

* A repository rename event moves the mirror path.
* Old paths redirect for 30 days.
