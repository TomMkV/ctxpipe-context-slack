# CTX-48: `GRAPH_DB_URI` default breaks knowledge graph on host

**Problem:** Default `redis://falkordb:6379` only resolves inside Compose; host dev gets `ENOTFOUND` unless `.env.local` sets `redis://localhost:6379`.

**Scope:** Document in runbook + `.env.example`; consider detecting host vs container or a single dev default that works for `pnpm dev` + `pnpm dev:infra`.

**Acceptance:** Fresh clone + `pnpm dev:infra` + `pnpm dev` + `GRAPH_DB_URI` documented; graph API doesn’t fail DNS for typical host setup.
