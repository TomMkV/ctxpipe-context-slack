# CTX-49: Stabilise `CODESEARCH_URL` for worker vs codesearch container

**Problem:** Random host port for codesearch + worker/Turbo env inheritance → stale URL after restarts → `resolve-ref` **401** while secrets match.

**Scope:** Pin codesearch to a fixed host port in `codesearch-docker-dev.sh`, or write `CODESEARCH_URL` into a file the worker reads, or document “restart `pnpm dev` after codesearch port changes” + add health log line with resolved URL.

**Acceptance:** Worker and backend always hit the same codesearch instance after Docker/Colima restarts; ingestion `resolve-ref` succeeds when infra is healthy.
