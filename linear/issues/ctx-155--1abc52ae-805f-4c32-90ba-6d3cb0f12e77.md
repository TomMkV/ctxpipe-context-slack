# CTX-155: Allow an owner to transfer organisation ownership

Owners cannot transfer ownership without removing themselves first, which locks the org if they are the last owner. We need an explicit transfer that swaps roles in one transaction.

## Acceptance

* An owner can nominate another member as owner.
* The previous owner becomes an admin in the same request.
