# CTX-165: Map GitHub team access onto individual repository mirrors

Repository visibility is all-or-nothing for the org. GitHub teams that can see one repo should not automatically see its siblings in search.

## Acceptance

* A GitHub team maps to a membership on the mirrored repository only.
* Search honours that membership.
