# CTX-173: Reconnecting Slack duplicates the workspace connection

Disconnecting and reconnecting Slack creates a second connection and re-imports every channel. The old connection stays active and both write to the mirror.

## Acceptance

* Reconnect updates the existing connection.
* Channel rows are upserted on Slack channel id.
