# CTX-142: Session stays bound to the previous org after switching

Switching organisations leaves the session cookie bound to the previous org for up to a minute. API calls in that window return data from the wrong tenant.

## Acceptance

* Org switch rotates the session immediately.
* A follow-up request cannot read the previous org's projects.
