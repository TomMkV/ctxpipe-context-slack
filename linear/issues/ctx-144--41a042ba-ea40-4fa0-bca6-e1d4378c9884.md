# CTX-144: Password reset tokens expire after 15 minutes

Password reset links are documented as valid for one hour, but the token store expires them at 15 minutes. Support has had three tickets this week from users who followed the email later the same morning.

## Acceptance

* Token TTL matches the copy in the email.
* Expired tokens return a specific error, not a generic 400.
