# CTX-113: Update our packages release workflow to use trusted publishers with github actions

Refers to [this documentation](<https://docs.npmjs.com/trusted-publishers>) from npm for github actions

As this is only supported for github hosted runners, use github hosted runners instead of blacksmith just for the release workflow

If there is any manual set up that we have to do in npm, please note them in the PR

## Done — CTX-113

The **Release** job in [`.github/workflows/deploy.yaml`](<https://github.com/ctxpipe-ai/ctxpipe/blob/cursor-cloud-npm-trusted-publishers-6c47/.github/workflows/deploy.yaml>) now uses npm **trusted publishing (OIDC)** on **GitHub-hosted** runners.

**Draft PR:** [https://github.com/ctxpipe-ai/ctxpipe/pull/192](<https://github.com/ctxpipe-ai/ctxpipe/pull/192>)

### What changed

| Before | After |
| -- | -- |
| `blacksmith-4vcpu-ubuntu-2404` | `ubuntu-latest` (release job only) |
| `NPM_TOKEN` + manual `~/.npmrc` | OIDC via `id-token: write` + `setup-node` `registry-url` |
| Blacksmith checkout/setup-node/stickydisk | `actions/checkout@v4`, `actions/setup-node@v4` |
| — | `npm install -g npm@11.5.1` (trusted publishing minimum) |

Other deploy jobs (images, migrate, terraform, forge) still use Blacksmith.

### Manual npm setup (documented in the PR)

For **each** published package (`@ctxpipe/aws-cdk` and `ctxpipe`), on [npmjs.com](<http://npmjs.com>) → package **Settings** → **Trusted publishing** → **GitHub Actions**:

* **Repository:** `ctxpipe-ai/ctxpipe`
* **Workflow filename:** `deploy.yaml` (exact match)

After the first successful OIDC publish, you can optionally disallow tokens and revoke the legacy `NPM_TOKEN` secret.

**Repository:** `ctxpipe-ai/ctxpipe`
**Branch:** `cursor-cloud-npm-trusted-publishers-6c47`
