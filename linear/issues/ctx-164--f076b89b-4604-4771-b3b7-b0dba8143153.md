# CTX-164: Log the GitHub delivery id when a webhook signature fails

When a GitHub webhook signature fails we log "invalid signature" and drop the delivery id. Replay from the GitHub UI is then guesswork.

## Acceptance

* The log line includes the delivery id and event name.
* The body is not logged.
