# CTX-97: Allow customers to self-host ctx| with our battery-included aws-cdk package

Things to keep in mind:

* AWS Bedrock support for model. Currently, we support OpenAI compatible model with bearer token eg openrouter.ai but AWS bedrock requires aws iam
* Fargate + Postgres on Aurora + Neptune  + File system on EFS
* Docs on how to self-host for users
* Prebuild AI prompt or skills so they can get AI Agents to set it up
* Test via our AWS environment
* Supports custom domain (assuming customers already have their hosted zone set up)
