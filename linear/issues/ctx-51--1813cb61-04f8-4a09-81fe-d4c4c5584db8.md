# CTX-51: Dev: FalkorDB / Redis port conflicts on 6379

**Problem:** Standalone FalkorDB or tunnels on 6379 prevent Compose FalkorDB from binding.

**Scope:** Document `CTXPIPE_*` port overrides in `docker-compose.env.example` + “one FalkorDB listener per machine”.

**Acceptance:** Clear recovery steps when bind fails.
