# CTX-143: Require SSO for an organisation once an identity provider is connected

Enterprise customers need a per-organisation switch that rejects password login once SSO is configured. Today SSO is optional even after an IdP is connected.

## Acceptance

* Admins can require SSO for members.
* Existing sessions for password users are revoked on enable.
