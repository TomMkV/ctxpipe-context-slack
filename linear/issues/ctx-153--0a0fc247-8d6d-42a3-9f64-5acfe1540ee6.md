# CTX-153: Removing a member leaves their API tokens active

Deleting a member does not revoke API tokens they created. Those tokens keep working until they expire, which for personal tokens is never.

## Acceptance

* Member removal revokes tokens owned by that user in the org.
* Subsequent calls with the old token return 401.
