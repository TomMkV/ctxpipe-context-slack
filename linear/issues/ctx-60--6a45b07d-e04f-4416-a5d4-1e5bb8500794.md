# CTX-60: MCP onboarding tweak for invitees

When an invitee is onboarded into the app, the MCP step still shows the two install MCP options, with the 'via raised PRs' option disabled. It should say (after checking or some validation) that 'XYZ repos have MCP files installed already' - and then shows the raw MCP JSON incase.

That feels more clear to the user. If, for whatever reason, the MCP files haven't been installed via PRs - then it would say MCP files not in repos.

Or, is this becoming too complicated? Should it just be the MCP JSON and nothing else?
