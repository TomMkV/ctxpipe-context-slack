# CTX-204: Linear issue webhooks arrive out of order and overwrite newer titles

Update webhooks for the same issue can land with an older updatedAt after a newer one. The mirror then reverts the title.

## Acceptance

* Ignore events whose updatedAt is older than the stored row.
* A replay of an old payload does not change the current title.
