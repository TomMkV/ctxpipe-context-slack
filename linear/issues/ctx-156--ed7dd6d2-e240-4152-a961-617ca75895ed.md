# CTX-156: Show city and country on active sessions

Session list in account settings shows device and IP, but not the approximate city. Security review asked for enough detail that a user can spot a foreign session without a raw IP.

## Acceptance

* Each session row shows city and country derived from the IP at issue time.
* We store the label, not a fresh lookup on every page view.
