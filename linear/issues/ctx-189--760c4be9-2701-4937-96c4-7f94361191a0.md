# CTX-189: CORS allows any origin when the request has no Origin header

A missing Origin is treated as allowed, and a browser extension can call the API with cookies.

## Acceptance

* Credentialed requests require an allow-listed Origin.
* Server-to-server calls without cookies are unchanged.
