# CTX-50: Docker context / Colima vs Docker Desktop confusion

**Problem:** `docker context` = Colima but Colima VM/socket dead → confusing “daemon not running” while another runtime might work.

**Scope:** Short troubleshooting in `AGENTS.md` or dev runbook: check `docker info`, Colima restart, `docker context use default` for Desktop.

**Acceptance:** One doc section agents can follow without guessing.
