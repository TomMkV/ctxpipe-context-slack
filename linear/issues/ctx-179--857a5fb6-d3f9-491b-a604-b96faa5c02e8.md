# CTX-179: Notion incremental sync misses edits inside synced blocks

Pages edited only inside a synced block do not change the parent last_edited_time we poll. Those edits never arrive until a full backfill.

## Acceptance

* Incremental sync follows synced-block children.
* A test page edited only in the block shows up within one poll.
