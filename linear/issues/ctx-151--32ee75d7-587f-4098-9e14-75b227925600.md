# CTX-151: Members list drops the last page when the count is a multiple of 25

The members page requests 25 rows at a time. When the total is an exact multiple of 25, the last page renders empty and the previous control disappears.

## Acceptance

* Exact multiples still show the final page of members.
* Empty state only appears when the org has no members besides the caller.
