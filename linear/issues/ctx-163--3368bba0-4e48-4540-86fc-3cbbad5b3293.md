# CTX-163: GitHub installation retries create duplicate repository mirrors

GitHub redelivers installation webhooks when our handler is slow. Each retry inserts another repository row for the same GitHub id.

## Acceptance

* Repository upsert keys on installation id plus GitHub repo id.
* A replayed webhook does not create a second mirror.
