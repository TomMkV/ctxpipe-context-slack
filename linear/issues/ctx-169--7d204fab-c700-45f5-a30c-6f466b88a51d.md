# CTX-169: GitHub review replies lose their parent comment

Review comment replies are stored as top-level comments. The in_reply_to id from GitHub is ignored, so threads render flat.

## Acceptance

* Replies nest under the parent review comment.
* A deleted parent leaves the reply in place with a note.
