# CTX-167: Archive a repository mirror when the GitHub App loses access

If the GitHub App loses access to a repo we keep serving the last mirror forever. The repository should be marked archived and hidden from default search.

## Acceptance

* An installation_repositories removed event archives the mirror.
* Restoring access unarchives it.
