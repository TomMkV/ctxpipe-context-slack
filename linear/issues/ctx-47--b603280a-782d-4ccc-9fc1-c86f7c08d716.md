# CTX-47: Don’t block `pnpm dev` when Docker is down (codesearch)

**Problem:** `scripts/codesearch-docker-dev.sh` exits the whole dev script if `docker info` fails, so backend/UI/worker never start even when you only need Postgres + graph locally.

**Scope:** Make codesearch optional in host dev (warn + unset `CODESEARCH_URL` or skip container start), or gate behind a flag (e.g. `CTXPIPE_CODESSEARCH=0`).

**Acceptance:** With Docker off, `pnpm dev` still starts backend + UI + worker; codesearch-dependent features fail gracefully with a clear message.
