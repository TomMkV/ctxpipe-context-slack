# CTX-148: Old two-factor recovery codes stay valid after regeneration

Regenerating two-factor recovery codes leaves the previous set valid until the user signs in again. Both sets succeed at the recovery endpoint.

## Acceptance

* Regeneration revokes the previous codes in the same transaction.
* A test covers use of an old code after regenerate.
