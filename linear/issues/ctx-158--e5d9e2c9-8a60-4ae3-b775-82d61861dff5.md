# CTX-158: Login rate limit locks out every user behind the same NAT

Rate limiting on login is per IP only. A shared office NAT locks out the whole floor after a few bad passwords. Limit by IP plus email hash.

## Acceptance

* Failed attempts are counted per account as well as per IP.
* A burst against one account does not block a different account on the same IP.
