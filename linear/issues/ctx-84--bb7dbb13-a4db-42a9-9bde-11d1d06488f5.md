# CTX-84: Update docs with Knowledge Graph page

Our docs are missing a page on the knowledge graph UI (at /knowldge-graph).

The UI has lots of elements which could be overwhelming to new users.

For now, for this ticket, work on updating the docs (a seperate ticket will work on onboarding users).

The page should have information like:

* Purpose of the page and of visualising the knowledge graph - and some definitions
* View activity  (last updated & activity chart)
* Explore the graph with zoom and pan
* See overall metrics with nodes and edges - and their definitions 
* Search - purpose and scope
* Legend - acts as a filter and feedback to what is visualised - toggleable
* Clicking on nodes; shows close relationships and why, and opens node inspector
* Node inspector has lots of functionality:
  * Metadata in detail and explanations
  * Copy id function 
  * Ask Ctx| function and purpose 
* Etc

## What I did

Resolved **CTX-84** by adding in-app documentation for the knowledge graph UI.
