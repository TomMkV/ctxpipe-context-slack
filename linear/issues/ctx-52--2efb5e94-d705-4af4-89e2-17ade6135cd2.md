# CTX-52: Surface ingestion/workflow failure in the UI (not perpetual “indexing”)

**Problem:** OpenWorkflow runs fail (e.g. `resolve-ref` 401) but repos stay `index_ready = false` and UI still suggests indexing.

**Scope:** Expose last workflow status/error on repo row or poll `workflow_runs`; show failed state + retry.

**Acceptance:** User sees failure reason when ingestion fails; can retry without reading server logs.
