# CTX-134: Post-launch tidy up

Some things caught by Fable in a review. FWIW, but could be some tidy up here in case.

* ~~**No LICENSE file.** The README declares ELv2 and there's a badge, but the root file listing has no LICENSE file — which means GitHub shows no license chip, and ELv2 actually requires the license text to be included. Worse, the badge hyperlinks to the shields.io image URL rather than to the license itself. For a company whose pitch includes "audit it, self-host it," a missing licence file is the first thing a legally-cautious evaluator hits. This is a ten-minute fix and I'd do it before anything else.~~
* **The 21.9 KB root AGENTS.md is a screenshot waiting to happen.** You're about to publish a blog post citing the ETH Zurich finding that context files reduce success and inflate cost — and your own root context file is 22 KB. A sharp commenter will connect those dots within hours of the launch post. You have two good options: trim it hard (most of the Cursor Cloud runbook detail could live in `.agents/`), or — the move I'd actually make — *lean in* with two sentences at the top: something like "This file is exactly the sprawl ctxpipe exists to replace; until we've fully migrated our own context into ctx|, it's also our honest baseline." That turns the gotcha into the pitch.
* ~~**README and AGENTS.md disagree about what's shipped.** README lists "Git-backed instructions and memory" under *Coming soon*, while AGENTS.md documents ~~`~~npx ctxpipe memory init~~`~~, the local memory MCP, and ADR-021 as working today. Since the local memory harness is now in your LinkedIn copy ("agents write what they learn to plain .md files in your repo"), the README needs to catch up — otherwise the post promises something the repo's front page says isn't ready.~~
* **21 open PRs against 8 stars and 3 contributors.** I'd guess that's an agent-generated queue, but a cold evaluator reads it as either neglect or chaos. Triage before launch: merge, close, or convert to draft. The PR tab is part of the landing page.
